# Лендинг: ИИ-агент со сводкой по бизнесу в Telegram

Одностраничный сайт для проверки спроса. Сегменты: селлеры маркетплейсов, сети шаурмы, блогеры.

- `index.html` — вся страница одним файлом, без сборки.
- Заявка открывает Telegram с готовым сообщением на @ngafitulin, сайт ничего не хранит.
- Публикуется через GitHub Pages из ветки `main`.
