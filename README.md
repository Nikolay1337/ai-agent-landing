# ИИ-агенты на практике: внедрение и обучение

Статичный сайт из трёх страниц, без сборки. Каждая страница — один HTML-файл.

- `index.html` — главная: развилка «Для бизнеса» / «Обучение».
- `business/index.html` — Telegram-бот с отчётами для бизнеса, пилот (14 дней бесплатно, 2 000 ₽ + 500 ₽/мес).
- `school/index.html` — онлайн-обучение работе с ИИ-агентами: программа из 7 модулей, запись в первый поток.

Все заявки открывают Telegram с готовым сообщением на @ngafitulin, сайт ничего не хранит.
Публикуется через GitHub Pages из ветки `botgoogletable` (ветка по умолчанию). Ссылки между страницами относительные, поэтому сайт работает и на github.io, и на своём домене.
